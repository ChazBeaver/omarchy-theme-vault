# Blue Sky

A dark teal palette drawn from shaded rooms and distant mountains, with
clear azure accents, soft cloud-white text, sunlit leaf greens, river cyan,
and warm cream and wood tones. Muted flower colors round out the palette.
Five wallpapers pair blue skies with fields, mountains, rivers, and plants.

The palette in `colors.toml` is the source of truth. Omarchy generates matching
Quickshell, terminal, Neovim, and application themes when it is selected.

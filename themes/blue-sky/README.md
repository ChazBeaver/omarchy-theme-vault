# Blue Sky

A dark blue palette drawn from open skies and shaded rooms, with cloud-white
text, clear sky-blue accents, river teal, leafy greens, and warm sunlight.
Five wallpapers pair blue skies with fields, mountains, rivers, and plants.

The palette in `colors.toml` is the source of truth. Omarchy generates matching
Quickshell, terminal, Neovim, and application themes when it is selected.

# I Want to Believe

A near-black, desaturated Omarchy theme generated by Aether from the X-Files UFO hill wallpaper: olive-grey text, steel-blue accent, and muted moss, sage, and fog tones.

The palette in `colors.toml` is the source of truth. Omarchy generates matching
Quickshell, terminal, Neovim, and application themes when it is selected.

# Alpine Lake

A dark alpine Omarchy theme derived from Maroon Bells (Colorado) and Half Dome (Yosemite) photos: deep pine-green backgrounds, mist-grey text, glacial blue accent, and muted earth and meadow tones.

The palette in `colors.toml` is the source of truth. Omarchy generates matching
Quickshell, terminal, Neovim, and application themes when it is selected.

# Deep Blue

A personally maintained copy of One Dark, with a charcoal background and
blue accents. The palette, original wallpapers, previews, lock image, icons,
and keyboard color are preserved from the installed source revision.

Edit this theme in `omarchy-theme-vault`. After publishing changes, run
`./themes.sh update deep-blue` from Hyprdots and select `omarchy theme set deep-blue`.
Omarchy generates terminal and editor configurations from `colors.toml`.

See [UPSTREAM.md](UPSTREAM.md) for the original source and license.
This theme was previously named Blue Sky; the earlier Blue Sky theme before
that is now [Blue Green](../blue-green/README.md).

The upstream deep blue sky and clouds photograph is the default wallpaper,
followed by two personal underwater and ocean photographs.
See [WALLPAPERS.md](WALLPAPERS.md) for the default, filenames, and provenance.

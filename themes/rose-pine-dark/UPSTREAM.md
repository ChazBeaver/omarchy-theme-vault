# Rosé Pine Dark source

- Original repository: https://github.com/guilhermetk/omarchy-rose-pine-dark.git
- Preserved revision: `ebe6ad030abd32cb6689b081ba0767c785441cb0`
- Palette: Rosé Pine Main, credited to [Rosé Pine](https://rosepinetheme.com/).
- Original documentation: [upstream/README.md](upstream/README.md).
- Local adoption recorded: 2026-10-25.

The active `colors.toml`, `icons.theme`, and `chromium.theme` are copied
byte-for-byte from the installed source revision. The selected wallpaper
is also unchanged; its filename is now `backgrounds/00-space.webp`.

The following upstream files are archived as reference, preserving the
behavior of the community installation where Omarchy filtered them:

- `upstream/neovim.lua`
- `upstream/vscode.json`

Omarchy generates the active terminal and editor configuration from the
palette. The archived files are not loaded automatically. The remaining
upstream wallpapers, screenshots, unlock images, and other image assets are
omitted so this theme retains only the selected wallpaper and its preview link.
The archived README still refers to those omitted upstream assets.

No theme-local license file was supplied in the installed snapshot. Original
authors retain their rights and credits. This maintained copy and its image
are versioned in the theme vault; no redistribution license is asserted here.

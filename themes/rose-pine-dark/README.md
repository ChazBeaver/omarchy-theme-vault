# Rosé Pine Dark

A personally maintained copy of the Rosé Pine Main dark theme, with its
original palette, icon selection, and Chromium color preserved.

![Rosé Pine Dark wallpaper and theme preview](backgrounds/00-space.webp)

The only wallpaper is `backgrounds/00-space.webp`, the original high-resolution
space landscape selected from the desktop reference on 2026-10-25.
`preview.webp` is a relative link to that same file, so the wallpaper and
preview share one tracked image asset. See [WALLPAPERS.md](WALLPAPERS.md).

Edit this theme in `omarchy-theme-vault`. After publishing changes, run
`./themes.sh update rose-pine-dark` from Hyprdots and select it with
`omarchy theme set rose-pine-dark`. Hyprdots pins this directory in the
personal vault; it no longer follows the original upstream repository.

Omarchy generates active terminal/editor configuration from `colors.toml`.
The upstream Neovim and VS Code settings are archived under `upstream/` and
are not loaded automatically. See [UPSTREAM.md](UPSTREAM.md) for attribution.

# Mars source

- Original repository: https://github.com/steve-lohmeyer/omarchy-mars-theme.git
- Preserved commit: `255a8cb5331fc41cc9f976c643dbe5f9db38f4fd`

Preserved for private personal use from the installed version. Original
authors retain their credits and licenses; this copy is maintained in
`omarchy-theme-vault` and does not fetch files from the original repository.
Original documentation and license files are retained when supplied.

The following upstream files are kept under `upstream/` as reference only,
matching the files Omarchy excluded when this was an installed community clone:

- `alacritty.toml`
- `ghostty.conf`
- `neovim.lua`

Omarchy generates the active terminal, editor, and Lua configurations from
`colors.toml`. The archived files are not loaded automatically.

`colors.toml` was derived from the original `alacritty.toml` using the
installed Omarchy converter, exactly as community-theme selection does.

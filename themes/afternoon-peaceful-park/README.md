# Afternoon Peaceful Park

A dark slate-and-plum palette drawn from the park cafe at sunset: warm cream
text, golden sunlight, soft sky blue, leafy teal and sage, and muted rose wood.

`backgrounds/00-afternoon-park.png` is the default wallpaper and theme-picker
preview. Its `00-` prefix places it first in Omarchy's sorted wallpaper list.
Selecting the same theme repeatedly still cycles its wallpapers.

The palette in `colors.toml` is the source of truth. Omarchy generates matching
Quickshell, terminal, Neovim, and application themes when it is selected.

# Jellyfish Pink Blue

A near-black Omarchy theme generated by Aether from a pink-and-blue jellyfish wallpaper: rose-tinted text, periwinkle accent, and bioluminescent coral, salmon, and violet tones.

The palette in `colors.toml` is the source of truth. Omarchy generates matching
Quickshell, terminal, Neovim, and application themes when it is selected.
